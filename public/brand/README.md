# Legacy implementation assets

For NEXUS 2.0, the canonical source is [../../brand/README.md](../../brand/README.md). This directory is preserved because the current application and install metadata reference it. Do not use its Blue Reactor tokens, NEXUS marks or label templates as current design authority.

The `status: approved` field in `brand-tokens.json` is historical Blue Reactor metadata; it does not override the owner's later NEXUS 2.0 decision. Files are retained byte-for-byte to avoid changing runtime behavior.

Science By Hugs, CORE and PULSE assets are not redesigned by this decision. Product-label templates and generated vials are not verified evidence of actual physical packaging.
